Rule-Based Anomaly Detection
Per-sensor min/max/slope thresholds from anomaly_rules.csv. Slope computed via groupby(run_id).diff() — no cross-run bleed.

Statistical Anomaly Detection
Rolling z-score per run via groupby.transform(rolling). Window resets at run boundaries. Threshold: |z| > 3.0.

3
Score Normalisation
Rule scores (physical units) ÷ signal σ → dimensionless. Stat z-scores kept as-is. Enables fair cross-sensor aggregation.

Pearson Correlation + FFT Lag
Global N×N Pearson matrix. FFT cross-correlation O(N log N) per signal pair vs reference. Max lag ±30 samples (±3 s at 100 ms).

Anomaly Detection — Algorithm Detail
Rule-Based Detection — Per-Run Safe Slope
For each sensor rule in anomaly_rules.csv:

Min/Max: flag if value < min or value > max, score = deviation magnitude

Slope: df.groupby("run_id")[sensor].diff() / sampling_s
→ first sample of each run = NaN (no cross-run artifact)
→ flag if |slope| > max_abs_slope

Output score is in physical units → normalised in Step 3 by signal σ.
Statistical Detection — Per-Run Rolling Z-Score
For each numeric signal:

rolling_mean = groupby("run_id").transform(lambda x: x.rolling(W).mean())
rolling_std = groupby("run_id").transform(lambda x: x.rolling(W).std())

→ rolling window never crosses run boundary
→ min_periods = max(5, W/2) to avoid early NaNs

z = (value − μ) / σ   flag if |z| > 3.0
Score = |z| (already dimensionless — no normalisation needed).
