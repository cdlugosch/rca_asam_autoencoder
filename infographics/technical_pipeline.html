MDF Transformation — mdf_io.py

Converts raw automotive measurement files into structured, metadata-enriched parquet files for downstream processing

TRIGGER
⚡

Data Dump Event

Measurement data is captured when a specific event occurs on the vehicle:

🔴 Issue trigger — DTC fired, fault detected, technician initiated
🟡 Test-run trigger — Scheduled measurement campaign, baseline capture
→
INPUT
📂

MF4 / MDF Source Files

Raw ASAM MDF4 files placed into a VIN-structured folder hierarchy:

mdf_files/
 └── WBA000001/  (VIN)
    ├── iss1234567ABC/  (issue)
    │   └── WBA000001_fault_run_01.mf4
    └── none/  (test-run)
        ├── WBA000001_normal_run_01.mf4
        └── WBA000001_normal_run_02.mf4
→
SIDECAR
📋

run_metadata.csv

Maps every run_id to its full context. Provided as part of the handover package:

run_id, vin, issue_id, testrun
WBA..._fault_01, WBA000001, iss1234567ABC, TR-001
WBA..._normal_01, WBA000001, none, TR-002
WBA..._normal_02, WBA000001, none, TR-003

VIN + issue_id are also derived from the folder path as a fallback.

→
PROCESSING
⚙️

asammdf Parsing & Cleaning

Per MDF file:

🔹Parse all channels via asammdf
🔹Resample to 100 ms grid
🔹Drop all-NaN & constant columns
🔹Drop non-numeric channels
🔹Tag vin / issue_id / testrun columns
→
OUTPUT
💾

Intermediate Handover

Parquet files written into the same VIN/issue hierarchy, ready for AE processing or external system pickup:

intermediate/
 ├── run_metadata.csv
 └── WBA000001/
    ├── iss1234567ABC/
    │   └── fault_run_01.parquet
    └── none/
        └── normal_run_0{1,2}.parquet

Parquet Schema — Embedded Metadata Columns

  • 🔑
    run_id  — Unique run identifier (stem of MF4 filename)
    e.g. WBA000001_fault_run_01
  • 🚗
    vin  — Vehicle identification number
    From folder hierarchy or sidecar CSV
  • 🔴
    issue_id  — Issue tracker ID or none
    Prefix "iss" → from issue management system
  • 🧪
    testrun  — Test campaign identifier
    From sidecar CSV, e.g. TR-2026-001
  • 📊
    signal columns  — One column per physical channel
    Resampled at 100 ms, numeric, non-constant only

Data Quality & Cleaning Rules

  • 🗑️
    All-NaN columns dropped
    Channels that never produced a valid reading
  • 🔢
    Non-numeric columns dropped
    Strings, labels, status enums excluded
  • 📏
    Constant columns dropped
    Zero-variance signals carry no diagnostic value
  • ⏱️
    Resampled to 100 ms uniform grid
    Enables aligned window-based processing downstream
  • 🏷️
    Metadata columns protected
    run_id, vin, issue_id, testrun exempt from cleaning

AE Anomaly Detection — ae_anomaly.py

Windowed MLP autoencoder trained on normal (issue_id=none) runs · Per-signal reconstruction error thresholding · VIN-aware model management

INPUT
📦

Load All Parquets

Recursively scans intermediate/ for all *.parquet files. Concatenates into a single DataFrame.

Metadata cols (vin, issue_id, testrun) are preserved but excluded from signal processing.

→
DATA SPLIT
✂️

Automatic Training / Inference Split by issue_id

No manual run list required. The issue_id column drives the split automatically:

🟢 Training runs
All rows where issue_id == "none"
→ Baseline / normal behaviour only
→ Cannot be contaminated by fault data
🔴 Inference runs
All loaded runs (including training)
→ Anomaly scores computed for every run
→ Normal runs serve as validation baseline
MODEL
MODE

Configured via MODEL_MODE in INPUT_MANIFEST — single switch, no path management required

🟢 GENERATE — Train & Save

  • Filter training windows from issue_id = "none" runs
  • Create sliding windows of size W=20 (2 s @ 100 ms)
  • Flatten: W × n_signals → feature vector
  • Fit StandardScaler on training windows
  • Train MLP autoencoder (X→X reconstruction) arch: [64, 16, 64]
  • Compute per-signal p95 reconstruction error thresholds on training data
  • Save model bundle to output/models/<VIN>/<VIN>_<YYYYMMDD>.joblib
OR

🟣 LOAD — Reuse Existing Model

  • Derive VIN from loaded data (df["vin"].mode())
  • Scan output/models/<VIN>/ for <VIN>_*.joblib
  • Auto-select most recent by YYYYMMDD filename sort
  • Restore ae, scaler, thresholds, signal_cols, window_size
  • Validate that all model signals are present in new data
  • No retraining — inference only on new fault data
  • Model can be applied to any run from the same VIN
WINDOWING
🪟

Sliding Window Extraction

Per run, extract overlapping windows:

Step=1 sample, W=20 → 581 windows per 600-row run

→
NORMALISE
📐

StandardScaler Transform

Each window flattened to shape (W × n_signals,) and z-score normalised using the scaler fitted on training data only.

Ensures consistent signal scale across all runs regardless of absolute sensor ranges.

→
RECONSTRUCT
🧠

Autoencoder Inference

MLP (X→X) reconstructs each window. Reconstruction error = MSE per signal per window:

error[t, signal] = (x[t,s] − x̂[t,s])²

High error = signal behaves differently from the learned normal baseline

→
THRESHOLD
🎯

Per-Signal p95 Thresholds

Each signal has its own anomaly threshold = p95 of its training reconstruction error.

Adapts to different signal variabilities. is_anomaly = error > threshold[signal]

score_normalized = error / threshold → comparable across signals

→
OUTPUT
📤
